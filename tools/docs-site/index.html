mineflayer-bridge API

Bots built with mineflayer draw HUDs, menus, world overlays and commands inside a real player's Minecraft client. The mod is client-side only and never sends packets to the game server.

Node

Plugin reference

The mineflayer-bridge package: hubs, layers and shapes, HUD, menus, commands, prompts, shared objects and defineExtension.

 Java

Mod extension API

For mods that extend the bridge: BridgeExtension, the registrar, message and store handlers, events and thread rules.

 Java

Client extension API

For mod extensions that add to the game: ClientExtension, home tabs, bot buttons, keys, input and render hooks, and ClientBridge.

Install the plugin

npm install mineflayer https://github.com/Pix3lPirat3/mineflayer-bridge/releases/download/v{{version}}/mineflayer-bridge-{{version}}.tgz

Load it into a bot

import { bridge } from 'mineflayer-bridge'

bot.loadPlugin(bridge())
